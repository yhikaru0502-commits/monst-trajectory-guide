モンスト軌道ガイド Web v1.4

【表示修正】練習モードはスクリーンショットの左上 (0,0) を画面左上に固定し、画面幅に合わせて縦横比を保ったまま描画します。上下方向の自動センタリングを廃止。メニューは右下に配置し、☰で開閉できます。

スクショ内のステータスバーも画像の一部として表示します。iOSの実際のステータスバーとホームインジケーターはOS管理のためWeb側で完全に消せない場合があります。Safariタブ内ではブラウザUIを消せないため、ホーム画面に追加して起動してください。

画面のどこからでもドラッグで角度を指定できます。固定壁と1024段階スナップ、画像保存は維持。

GitHub Pages: ZIP内の6ファイルをリポジトリ直下へ上書きしてください。
