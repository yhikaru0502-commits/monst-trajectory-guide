モンスト軌道ガイド Web v1.3

ホーム画面から起動して「全画面・練習モード」にすると、スクリーンショットを画面の左上から画面幅に合わせて描画します。撮影元と同じ画面比率なら画面全体に一致します。ステータスバーも画像の一部です。

iPhone: Safariの共有メニューから「ホーム画面に追加」し、ホーム画面のアイコンから起動してください。Safariのタブ内ではブラウザのバーは非表示にできません。iOSのステータスバーはOS管理のため表示が重なる場合があります。

メニューは右下の☰で開閉。全体表示に切替で従来の収まる表示へ変更できます。壁座標は元画像基準で維持。

GitHub Pages: ZIP内の6ファイルをリポジトリ直下へ上書きしてください。
