モンスト軌道ガイド Web v0.9
変更：反射ごとに色分け（ON/OFF）、接点の丸・番号を大きく、元画像解像度でのPNG保存にも適用。
固定壁・反射計算はv0.8から変更なし。
GitHubリポジトリのルートに6ファイルをアップロードし、既存ファイルを上書き（Commit changes）してください。
iPhoneではSafariで更新後にページを再読み込みしてください。旧表示が残る場合はサイトのキャッシュを消してください。

・反射点の円を50%透過に変更（赤／黄）
・真の反射位置を中央の小さな点で明示
・番号を円の外に移動して床模様と接点を隠さない
・固定壁座標と軌道計算は変更なし
